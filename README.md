# ZIP Сжатие — приложение для Android

Простое приложение: выбираешь файлы, нажимаешь «Сжать в ZIP», указываешь, куда сохранить. Готовым архивом можно сразу поделиться через Telegram, WhatsApp или почту.

Что умеет:
- выбор нескольких файлов сразу (из «Загрузок», галереи, Google Диска и т.п.);
- приём файлов через «Поделиться» из других приложений;
- своё имя архива;
- максимальное или обычное сжатие;
- показывает, сколько места сэкономлено;
- если два файла называются одинаково, второй переименовывается в «имя (2)».

Разрешения не нужны: файлы выбираются через стандартное окно Android.

---

## Как получить APK

### Способ 1 — через GitHub (без установки программ)

1. Зарегистрируйтесь на https://github.com и создайте новый репозиторий (кнопка **New**).
2. Нажмите **uploading an existing file** и перетащите туда **всё содержимое** этой папки (включая скрытую папку `.github`). На Mac скрытые папки показываются сочетанием Cmd + Shift + точка.
3. Нажмите **Commit changes**.
4. Откройте вкладку **Actions**, там запустится «Собрать APK» (около 3–5 минут).
5. Когда появится зелёная галочка, откройте сборку и внизу скачайте **ZIP-Szhatie-apk**. Внутри будет `app-debug.apk`.

### Способ 2 — через Android Studio на Mac

1. Установите Android Studio: https://developer.android.com/studio
2. **File → Open** и выберите эту папку. Дождитесь, пока закончится загрузка (Gradle sync).
3. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл появится здесь: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон (Samsung)

1. Перекиньте `app-debug.apk` на телефон (через Telegram себе, Google Диск или кабель).
2. Откройте файл на телефоне. Если появится вопрос — разрешите «Установку из неизвестных источников» для этого приложения (например, «Мои файлы»).
3. Нажмите «Установить». Если Google Play Protect предупредит о неизвестном разработчике, нажмите «Всё равно установить».

## Важно знать

Фото (JPG), видео, PDF и Office-файлы (docx, xlsx) уже сжаты внутри, поэтому ZIP почти не уменьшит их размер. Зато удобно собрать много файлов в один. Текст, таблицы CSV, BMP-картинки и другие несжатые файлы уменьшаются в разы.
